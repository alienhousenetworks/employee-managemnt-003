# Custom HR domain

This is an application-owned HR self-service domain, not an ERPNext/Frappe extension. It currently contains attendance entries, leave requests and general employee requests. It is not a payroll engine and must not be represented as one. Before production, add audited role/manager approval policies, work schedules/holiday calendars, leave accrual/balance rules, correction workflows, offboarding, document lifecycle, encryption/retention rules and generated reviewed migrations.
